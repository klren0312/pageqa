# 冒烟测试页面设计文档

## 概述

创建一个用于冒烟测试的示例页面，具备路由切换、表单填写、文件上传、提交表单等功能。该页面用于测试 pageqa 的各种功能，并提供对应的测试用例文件。

## 目标

1. 创建一个示例 HTML 页面（`examples/smoke-test-page.html`）
2. 创建对应的 pageqa 测试用例文件（`examples/smoke-test.md`）
3. 页面支持 Hash 路由切换
4. 页面包含多种表单字段类型
5. 页面支持原生文件上传
6. 页面支持表单提交后显示成功消息

## 文件结构

```
examples/
├── smoke-test-page.html   # 冒烟测试示例页面
└── smoke-test.md          # pageqa 测试用例文件
```

## 页面设计

### 路由规划

- `#/` - 首页（导航入口）
- `#/form1` - 表单页面 1（包含所有字段类型）
- `#/form2` - 表单页面 2（另一个表单，用于测试路由切换）
- `#/upload` - 文件上传页面

### 导航栏

- 顶部导航栏，包含 4 个链接
- 当前激活的路由高亮显示
- 使用 `hashchange` 事件监听路由变化

### 表单字段设计

#### 表单页面 1（`#/form1`）

1. **文本输入框**：姓名（必填）
   - 类型：`text`
   - 占位符：`请输入姓名`

2. **下拉选择框**：城市（必填）
   - 类型：`select`
   - 选项：`北京`, `上海`, `广州`, `深圳`

3. **复选框**：兴趣爱好（多选）
   - 类型：`checkbox`
   - 选项：`阅读`, `运动`, `音乐`, `游戏`

4. **单选按钮**：性别（必填）
   - 类型：`radio`
   - 选项：`男`, `女`

5. **日期选择器**：出生日期（必填）
   - 类型：`date`

6. **提交按钮**
   - 文本：`提交表单`

#### 表单页面 2（`#/form2`）

1. **文本输入框**：邮箱（必填）
   - 类型：`email`
   - 占位符：`请输入邮箱`

2. **下拉选择框**：职业（必填）
   - 类型：`select`
   - 选项：`学生`, `工程师`, `设计师`, `产品经理`

3. **提交按钮**
   - 文本：`提交表单`

#### 文件上传页面（`#/upload`）

1. **文件选择按钮**
   - 类型：原生 `<input type="file">`
   - 支持文件类型：图片、文档

2. **已选文件列表**
   - 显示选择的文件名
   - 支持多文件选择

3. **上传按钮**
   - 文本：`上传文件`

4. **上传结果显示区域**
   - 显示上传状态（成功/失败）
   - 显示上传的文件信息

### 交互设计

#### 路由切换

- 点击导航栏链接切换路由
- 监听 `hashchange` 事件
- 根据当前路由显示对应页面内容
- 默认路由为 `#/`

#### 表单填写

- 必填字段验证
- 填写后实时显示已填内容
- 提交时验证所有必填字段
- 验证失败时显示错误提示

#### 文件上传

- 选择文件后显示文件名
- 点击上传按钮后显示上传状态
- 上传完成后显示成功/失败消息
- 支持多文件上传

#### 表单提交

- 提交后显示成功消息
- 不刷新页面
- 成功消息**常驻显示**（不自动隐藏）：自动化 agent 从「点击提交」到「回头断言」之间要经历若干次 LLM 往返（实测 2~6 秒），自动隐藏的 toast 会让断言必然看不到它
- 提交后重置表单字段

### 样式设计

- 使用简洁的现代 UI 设计
- 响应式布局，适配不同屏幕尺寸
- 清晰的表单布局和间距
- 按钮和输入框统一样式
- 错误提示使用红色文字
- 成功消息使用绿色背景

## 测试用例设计

### 测试场景

1. **路由切换测试**：验证可以在不同路由间切换
2. **表单填写测试**：验证可以填写所有字段类型
3. **文件上传测试**：验证可以选择和上传文件
4. **表单提交测试**：验证提交表单后显示成功消息

### 断言点

- 页面标题包含预期文本
- 表单字段可以正确填写
- 文件上传后显示文件名
- 提交表单后显示成功消息

## 技术实现

### HTML 结构

- 使用语义化 HTML 标签
- 使用 `id` 属性标识各个区域
- 使用 `data-route` 属性标识路由内容

### CSS 样式

- 使用内联样式或内部样式表
- 使用 Flexbox 布局
- 使用 CSS 变量统一颜色和间距

### JavaScript 逻辑

- 使用原生 JavaScript
- 实现 Hash 路由系统
- 实现表单验证和提交
- 实现文件上传功能
- 实现页面内容切换

## 约束条件

1. 页面必须可以直接在浏览器中打开（无需服务器）
2. 使用 Hash 路由（非 History 路由）
3. 使用原生文件上传（非组件库）
4. 提交表单后显示成功消息（不刷新页面）

## 验证标准

1. 页面可以在浏览器中正常打开
2. 路由切换功能正常
3. 表单填写功能正常
4. 文件上传功能正常
5. 表单提交功能正常
6. 测试用例可以正确执行
